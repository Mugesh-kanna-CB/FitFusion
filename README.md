# FitFusion – Personalized Fitness and Nutrition Management System

FitFusion is a web-based application designed to help users maintain a healthy lifestyle through personalized fitness and nutrition guidance. It calculates Body Mass Index (BMI) and provides workout plans and diet suggestions based on individual fitness goals.

## 🚀 Features

- User Registration and Login
- User Profile Management
- BMI Calculation
- Personalized Workout Recommendations
- Diet Suggestions
- Fitness Dashboard
- Goal-based Fitness Planning

## 🛠️ Technologies Used

**Frontend:**
- React.js
- TypeScript
- Tailwind CSS

**Backend & Database:**
- Supabase
- PostgreSQL

**Development Tools:**
- Visual Studio Code
- Git
- GitHub
- Vite

## 🎯 Project Goals

- Make fitness planning simple and accessible.
- Help users understand their BMI.
- Provide workout and diet suggestions based on fitness goals.
- Support users in maintaining a healthy lifestyle.

## ⚙️ Installation and Setup

Follow these steps to run FitFusion locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/FitFusion.git
```

### 2. Navigate to the Project Folder

```bash
cd FitFusion
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory.

Add your Supabase credentials:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
