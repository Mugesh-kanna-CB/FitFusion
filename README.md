# FitFusion – Personalized Fitness and Nutrition Management System

### Your Fitness Journey, Simplified.

FitFusion is a web-based fitness and nutrition management application designed to help users maintain a healthy lifestyle. It calculates Body Mass Index (BMI) using height and weight and provides workout plans and diet suggestions based on individual fitness goals, such as weight loss, muscle gain, and fitness maintenance.

---

## 📌 Project Overview

Managing fitness and nutrition can be challenging without proper guidance. FitFusion provides a simple platform where users can manage their fitness profiles, calculate their BMI, and access goal-based workout and diet recommendations.

The application aims to make fitness planning more accessible, organized, and convenient.

## ✨ Key Features

- **User Authentication:** Register and log in to access the application.
- **Profile Management:** Manage personal and fitness-related information.
- **BMI Calculator:** Calculate Body Mass Index using height and weight.
- **Workout Recommendations:** Get workout suggestions based on fitness goals.
- **Diet Recommendations:** View diet suggestions to support fitness goals.
- **Fitness Dashboard:** Access important fitness information in one place.
- **Goal-Based Planning:** Support for weight loss, muscle gain, and fitness maintenance.

## 🏗️ Application Workflow

1. User registers or logs into the application.
2. User enters personal and fitness information.
3. The system calculates the user's BMI.
4. User selects a fitness goal.
5. The system provides suitable workout and diet suggestions.
6. User views fitness information through the dashboard.

## ⚙️ Installation and Setup

Follow these instructions to run the project on your local machine.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/FitFusion.git
```

### 2. Navigate to the Project Directory

```bash
cd FitFusion
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory.

Add your Supabase project credentials:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Replace the placeholder values with your actual Supabase credentials.

**Note:** Never upload your `.env.local` file or secret API keys to GitHub.

### 5. Run the Application

```bash
npm run dev
```

Open the local URL displayed in your terminal to access FitFusion.

### 6. Create a Production Build

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.
